CASE-vahend: Lucidchart

Lühike ajalugu

  • Kes lõi: Ben Dilts ja Karl Sun (Lucid Software Inc.)
  • Millal arendus algas: 2008. aastal (esimeseks versiooniks oli 2010)
  • Miks loodi: See loodi pilvepõhiseks alternatiiviks Microsoft Visiole, et võimaldada meeskondadel reaalajas koos skeeme joonistada.
  • Kas arendus jätkub: Jah, see on üks maailma juhtivaid pilvepõhiseid platvorme.

Peamised funktsioonid

Lucidchart on visuaalne koostööplatvorm, mis võimaldab kiiresti luua voogdiagramme, UML-skeeme, ERD-sid (andmebaasid) ja traatmuudeleid (wireframes).

Microsoft Project

Ajalugu

Microsoft Project loodi Microsofti poolt ja avaldati esmakordselt 1984. aastal, algselt DOS-i jaoks. See oli üks esimesi projektihalduse tarkvaratooteid personaalarvutitele. Tööriist loodi selleks, et aidata projektijuhtidel projekte tõhusamalt planeerida, jälgida ja hallata. Arendus on jätkunud tänaseni ning nüüd on see saadaval nii töölauarakenduse kui ka pilveteenusena (Microsoft Project Online).

Peamised funktsioonid

  • 📅 Gantti diagrammid — projekti ajakavade ja ülesannete sõltuvuste visualiseerimine
  • 👥 Ressursihaldus — meeskonnaliikmete ja nende töökoormuse määramine ja jälgimine
  • 📊 Aruandlus — sisseehitatud aruanded edenemise, kulude ja tulemuslikkuse kohta
  • 🔗 Microsoft 365 integratsioon — töötab koos Teams, Excel ja SharePoint rakendustega
  • ☁️ Pilvejuurdepääs — saadaval veebis Microsoft Project Online kaudu

Ekraanipildid

Microsoft Project on endiselt üks enim kasutatavaid projektihalduse tööriistu maailmas, eriti suurettevõtetes. See toetab nii Waterfall kui ka Agile metoodikaid, muutes selle mitmekülgseks erinevat tüüpi projektide jaoks.

ProjectLibre

Ajalugu

  • 👤 Lõid: Marc O'Brien, Laurent Chretienneau, Larry Kaye
  • 📅 Asutatud: 2012
  • 💡 Miks: Tasuta avatud lähtekoodiga alternatiiv Microsoft Projectile
  • ✅ Arendus jätkub: Jah — ProjectLibre Cloud on arendamisel

Peamised funktsioonid

  • 📅 Gantt-diagrammid — ülesannete, ajajoonte ja sõltuvuste visualiseerimine (FS, SS, FF, SF)
  • 👥 Ressursside haldus — meeskonnaliikmete määramine ja töökoormuse jälgimine
  • 📁 MS Projectiga ühilduv — avab ja salvestab .mpp faile
  • 📊 WBS ja RBS vaated — töö- ja ressursijaotuse struktuuridiagrammid
  • 💰 Eelarve jälgimine — kulude haldus baastaseme ja tegelike kulude võrdlusega
  • 🖥️ Platvormideülene — töötab Windowsis, macOS-is ja Linuxis (Java-põhine)

Ekraanipildid

ProjectLibre on üks enim allalaaditud avatud lähtekoodiga projektihalduse tööriistu maailmas. See toetab klassikalist veekose planeerimist ning on laialdaselt kasutusel hariduses, väikeettevõtetes ja mittetulundusühingutes tasuta alternatiivina Microsoft Projectile. Tulev ProjectLibre Cloud toob platvormile reaalajas koostöö võimaluse.
